# Jewbuntu Icons

Mac-inspired icon theme for [Jewbuntu](https://github.com/rhecht/jewbuntu-skin), a fork of
**[MacTahoe icon theme](https://github.com/vinceliuice/MacTahoe-icon-theme) by vinceliuice**
(GPL-3.0, see `COPYING` and `AUTHORS`). Almost all of the artwork is upstream's: rounded
"squircle" app icons, Mac-blue folders and Mac-like colours.

## What this fork changes

Upstream includes a number of app icons that closely copy Apple's own app icons (the Finder
face, App Store, Safari, Photos, System Settings, a drive with the Apple logo, Pages/Numbers/
Keynote, Music, Maps, Notes, Calendar, Contacts, Calculator and others). Jewbuntu does not ship
those. They are replaced by **original Mac-style squircles**: a gradient tile and a white glyph,
generated by `tools/jewbuntu/make-originals.py` from `tools/jewbuntu/originals.json`. Glyphs come
from GNOME's Adwaita symbolic icons (CC BY-SA 3.0, GNOME Project), except two drawn for Jewbuntu.
File names are unchanged, so every app that used the old icon now shows the new one.

- Theme name: `Jewbuntu` (`Jewbuntu`, `Jewbuntu-dark`, `Jewbuntu-light`).
- Upstream previews and screenshots are removed (they showed the replaced icons).

## Install

Normally through the `jewbuntu-icons` package. By hand: `./install.sh` (see `./install.sh --help`).

To regenerate the originals (needs `adwaita-icon-theme`):

    python3 tools/jewbuntu/make-originals.py /usr/share/icons/Adwaita/symbolic src/apps/scalable
